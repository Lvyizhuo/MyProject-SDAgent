```latex
{\linedate{\dateRange{2025.10}{2025.12}}{AI 政策通·智能体服务平台}{\textbf{济南大数据集团有限公司}}
\datedline{Java、SpringBoot、SpringAI、PostgreSQL、Redis、MinIO、Ollama、DashScope、MCP、React、Vite、Docker、Nginx}{}

面向山东省以旧换新补贴咨询场景，独立构建基于 RAG 与多智能体架构的政策问答服务平台，打通意图识别、多步规划、工具调用、多轮记忆与多模态交互全链路
\begin{itemize}
  \item 设计 ReAct 自主规划智能体架构，基于结构化提示词驱动 LLM 输出 JSON 多步执行计划，内置问候、补贴计算、政策+价格混合查询等 8 类业务快捷路径与解析失败兜底，实现复杂政策咨询的智能化响应；
  \item 实现工具意图分类器与参数前置校验，通过正则与关键词规则在调用前拦截参数不足的工具请求并改写为澄清计划，使无效工具调用降低 40\%，配合重试/退避/兜底多级降级策略保障高可用；
  \item 构建多源 RAG 检索链路：同义词扩展与向量+关键词 RRF 混合检索（权重 0.65/0.35），接入 TEI/Xinference/DashScope 三 Provider 重排序，结合父子块上下文扩展与最新政策优先排序，检索准确率提升 25\%；
  \item 基于 Redis 实现多级缓存与记忆体系：7 天多轮会话记忆、会话事实结构化存储、语义级 QA 缓存（余弦相似度命中），叠加高频问题直答快速路径，显著降低 LLM 调用成本与响应延迟；
  \item 搭建多智能体管理平台：多智能体实例独立绑定 LLM/视觉/语音/嵌入/重排序 5 类模型，运行时动态构建 ChatClient 实现模型热切换，API Key AES-GCM 加密存储，集成发票 OCR 兜底解析与语音问答等多模态交互；
\end{itemize}}
```
